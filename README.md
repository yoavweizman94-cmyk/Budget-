# התקציב שלנו

אפליקציית רשת קטנה לניהול תקציב משפחתי משותף. מגדירים פעם אחת **הכנסות** ו**הוצאות קבועות**, מזינים פעם בשבוע את ה**הוצאות המשתנות**, ורואים בכל רגע **כמה נשאר להוציא החודש**.

- שני בני הזוג רואים ומעדכנים את אותם נתונים, כל אחד מהטלפון שלו, בזמן אמת.
- אפשר להוסיף אותה למסך הבית בטלפון, והיא נפתחת וגם שומרת הוצאות בלי קליטה (מסתנכרן כשהרשת חוזרת).
- אין שרת משלנו: האתר הוא קבצים סטטיים, והנתונים נשמרים בפרויקט Firebase חינמי שבבעלותכם.

## איך משתמשים

| לשונית | מה יש בה |
| --- | --- |
| **סיכום** | כמה נותר להוציא החודש, כמה זה יוצא ליום ולשבוע, פירוט לפי שבועות ולפי קטגוריות |
| **הוצאות** | ההוצאות המשתנות של החודש, מקובצות לפי שבוע. הכפתור "הוספת הוצאות" פותח טופס שבו מזינים כמה שורות בבת אחת |
| **קבועים** | הכנסות והוצאות קבועות. שינוי סכום חל מהחודש המוצג והלאה, כך שחודשים קודמים לא משתנים. אפשר לסמן פריט כחד-פעמי (למשל בונוס) |
| **הגדרות** | הזמנת בן/בת הזוג, קטגוריות, היום בחודש שבו התקציב מתחיל, גיבוי |

החישוב: **הכנסות − הוצאות קבועות − הוצאות משתנות = נותר להוציא**. רוצים לשים כסף בצד? הוסיפו "חיסכון" כהוצאה קבועה.

## הקמה (חד-פעמית, כ-10 דקות)

### 1. פרויקט Firebase

1. היכנסו ל-[console.firebase.google.com](https://console.firebase.google.com) עם חשבון Google ולחצו **Add project** (או Create a project). תנו שם כלשהו; את Google Analytics אפשר לכבות.

### 2. הפעלת כניסה באימייל וסיסמה

1. בתפריט הצד: **Build → Authentication → Get started**.
2. בלשונית **Sign-in method** בחרו **Email/Password**, הפעילו (Enable) ושמרו.

### 3. מסד הנתונים וכללי האבטחה

1. בתפריט הצד: **Build → Firestore Database → Create database**.
2. בחרו מיקום (למשל `me-west1` – תל אביב, או `eur3` – אירופה) ו-**Start in production mode**.
3. אחרי שהמסד נוצר, עברו ללשונית **Rules**, מחקו את מה שכתוב שם, הדביקו במקומו את כל התוכן של הקובץ [`firestore.rules`](firestore.rules) ולחצו **Publish**.

> השלב הזה חשוב: הכללים הם שמבטיחים שרק חברי התקציב שלכם יכולים לקרוא ולשנות את הנתונים.

### 4. קטע ההגדרות של האפליקציה

1. לחצו על גלגל השיניים ליד **Project Overview → Project settings**.
2. בלשונית **General**, תחת **Your apps**, לחצו על סמל הרשת `</>`, תנו כינוי ולחצו **Register app** (אין צורך ב-Firebase Hosting).
3. יוצג קטע קוד שמתחיל ב-`const firebaseConfig = {`. העתיקו אותו; תצטרכו אותו בשלב 6.

### 5. פרסום האתר ב-GitHub Pages

1. במאגר הזה ב-GitHub: **Settings → Pages**.
2. תחת **Build and deployment** בחרו **Deploy from a branch**, בחרו את הענף שבו נמצא הקוד ואת התיקייה `/ (root)`, ולחצו **Save**.
3. אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/Budget-/`.

> בחשבון GitHub חינמי, Pages עובד רק במאגר ציבורי. אין בקוד שום מידע אישי או סודי: הנתונים עצמם נמצאים ב-Firebase ומוגנים בכללי האבטחה.

### 6. כניסה ראשונה והזמנה

1. פתחו את כתובת האתר בטלפון, הדביקו את קטע ההגדרות משלב 4 ולחצו **חיבור**.
2. צרו חשבון (שם, אימייל וסיסמה) ולחצו **יצירת תקציב חדש**.
3. ב**הגדרות → הזמנת בן/בת הזוג** שלחו את הקישור בפרטי. מי שפותח אותו ויוצר חשבון מצטרף לאותו תקציב; הקישור כבר כולל את הגדרות ה-Firebase, כך שאין צורך להדביק אותן שוב.
4. אחרי ששניכם בפנים, כבו בהגדרות את **אפשר הצטרפות דרך קישור ההזמנה**.

**הוספה למסך הבית:** באייפון – ב-Safari, כפתור השיתוף ← "הוסף למסך הבית". באנדרואיד – ב-Chrome, תפריט ⋮ ← "התקנת האפליקציה" / "הוספה למסך הבית".

### לא חובה: לקבע את ההגדרות בקוד

כדי שהאתר יעבוד מכל מכשיר בלי להדביק הגדרות, אפשר לשים את קטע ההגדרות בקובץ [`js/firebase-config.js`](js/firebase-config.js) (יש שם דוגמה). המפתחות האלה אינם סודיים, הם רק מזהים את הפרויקט.

## פרטיות ואבטחה

- הנתונים נשמרים ב-Firestore בפרויקט שלכם בלבד. רק מי שרשום כחבר בתקציב יכול לקרוא או לכתוב (ראו `firestore.rules`).
- הצטרפות אפשרית רק עם קישור ההזמנה, שמכיל מזהה אקראי ארוך, ורק כל עוד ההצטרפות פתוחה בהגדרות.
- "הורדת גיבוי" בהגדרות שומרת קובץ JSON עם כל הנתונים, ואפשר לייבא אותו בחזרה.

## פיתוח

אין שלב build: קבצי HTML, CSS ו-JavaScript רגילים. ספריית Firebase מצורפת בתיקייה `vendor/`.

```bash
npm start   # שרת מקומי בכתובת http://localhost:8000
npm test    # בדיקות ללוגיקת החישוב (js/budget.js)
```

| קובץ | תפקיד |
| --- | --- |
| `js/budget.js` | חישובים טהורים: חודשי תקציב, שבועות, סיכום |
| `js/app.js` | הממשק: מסכים, טפסים, ניווט |
| `js/store-firebase.js` | שמירה וסנכרון מול Firebase |
| `js/store-local.js` | מצב הדגמה: שמירה בדפדפן בלבד |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |
| `sw.js` | פתיחת האפליקציה בלי רשת |

לבדיקה מול אמולטור מקומי של Firebase (`firebase emulators:start --only auth,firestore`), הוסיפו `"emulator": true` להגדרות השמורות בדפדפן תחת המפתח `budget.fbconfig`.
